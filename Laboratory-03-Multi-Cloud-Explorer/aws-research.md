AWS Management Console - web dashboard for managing all services. Also accessible via AWS CLI and mobile app.

## Four Core Services
1. EC2 (Elastic Compute Cloud) - virtual machines
2. S3 (Simple Storage Service) - object storage
3. RDS (Relational Database Service) - managed databases
4. Lambda - serverless compute
[Consider also: IAM for identity, VPC for networking]
 
## Three Advantages
1. Most mature and widest service catalog of any provider
2. Huge community, documentation, and third-party tool support
3. Strong, long track record with enterprise clients
 
## Typical Enterprise Use Cases
- E-commerce platforms
- Media streaming and hosting
- Big data analytics
- Fast-scaling startups
